# TripMate · ທ່ຽວນຳໝູ່

ເວັບແອັບ (PWA) ສຳລັບໄປທ່ຽວນຳໝູ່. ໃຊ້ໄດ້ທັງ iPhone ແລະ Android ໂດຍບໍ່ຕ້ອງຜ່ານ App Store.

- **ແຜນທີ່ສົດ** — ໝຸດຮູບໂປຣໄຟລ໌ຂອງໝູ່ທຸກຄົນ, ລູກສອນບອກທິດທາງ + ໄລຍະທາງ, ອັບເດດລ່າສຸດເມື່ອໃດ, ແບັດ (Android), ປຸ່ມນຳທາງໄປ Google Maps
- **ແຜນທີ່ 3 ແບບ** — ມາດຕະຖານ (ສະອາດ), ລາຍລະອຽດ (OpenStreetMap), ດາວທຽມ
- **📣 ຖາມຢູ່ໃສ** — ກົດໃສ່ບັດຂອງໝູ່ → ໂທລະສັບໝູ່ດັງ ແລະ ຂຶ້ນປຸ່ມ "ແຊຣ໌ຕຳແໜ່ງ"
- **ແຊັດກຸ່ມ** — ຂໍ້ຄວາມ, ຮູບ (ບີບອັດອັດຕະໂນມັດ), ສົ່ງຕຳແໜ່ງ, ຂໍ້ຄວາມດ່ວນກົດເທື່ອດຽວ ("ຢູ່ໃສແລ້ວ?", "ກຳລັງໄປ"…)
- **ນ້ອງປິນ + ກິມມິກແຈ້ງເຕືອນ** — ມາສຄອດແບບ anime ມາບອກທຸກແຈ້ງເຕືອນ: ແບນເນີຕົກລົງມາເດັ້ງໆ, ຫົວໃຈ/ກະດາດສີ/ດາວລອຍ, ສຽງສັງເຄາະ ແລະ ການສັ່ນແຕກຕ່າງກັນຕາມຊະນິດ. ຖາມຢູ່ໃສ ແລະ SOS ເປັນໜ້າຈໍເຕັມ ມີເສັ້ນໂຟກັສແບບມັງງະ
- **ແຈ້ງເຕືອນອັດຕະໂນມັດ 3 ແບບ** — ໝູ່ຮອດຈຸດນັດ (🎉), ແບັດໝູ່ເຫຼືອ ≤15% (🔋), ໝູ່ຫ່າງກຸ່ມເກີນ 1 ກມ (🧭). ແຕ່ລະອັນແຈ້ງຄັ້ງດຽວ ບໍ່ຍິງຊ້ຳ
- **ສະຕິກເກີນ້ອງປິນ** — 9 ໜ້າຕາ ສົ່ງໃນແຊັດ
- **ທົດລອງແຈ້ງເຕືອນ** — ແຖບທຣິບ → "ທົດລອງແຈ້ງເຕືອນ" ກົດເບິ່ງ/ຟັງທຸກແບບໄດ້ ໂດຍບໍ່ສົ່ງຫາໝູ່. ປິດກິມມິກໄດ້ (ປະຢັດແບັດ)
- **💰 ແຖບ "ເງິນ"** — ຄົນທີ່ຈ່າຍ: ກົດ "ເພີ່ມລາຍຈ່າຍ" → ໃສ່ຈຳນວນ (LAK/THB/USD) → ພິມວ່າຈ່າຍຫຍັງ → ເລືອກຄົນຈ່າຍ + ຄົນຫານ → ຖ່າຍບິນ → ບັນທຶກ. ແອັບສົ່ງການ໌ດເຂົ້າແຊັດ, ແຈ້ງໝູ່ ແລະ ຄິດສະຫຼຸບໃຫ້ທັນທີ: ລວມທັງໝົດ, ຍອດແຕ່ລະຄົນ, ໃຜຕ້ອງໂອນໃຫ້ໃຜ (ໂອນໜ້ອຍຄັ້ງທີ່ສຸດ), ປຸ່ມ "ໂອນແລ້ວ" ຫັກໜີ້
- **ຫານໃຫ້ໃຜ** — ເລືອກເປັນຄົນໆ; ເລືອກທຸກຄົນ = "ຫານທັງໝົດ"; ບໍ່ເລືອກໃຜ = "ບໍ່ຫານ" (ລາຍຈ່າຍສ່ວນຕົວ ບໍ່ມີໃຜຕ້ອງໂອນ). ປ້າຍນີ້ຂຶ້ນໃນລາຍການ, ລາຍລະອຽດ, ແຊັດ ແລະ CSV
- **ສົ່ງລົງແຊັດ** — ບັນທຶກແລ້ວສົ່ງການ໌ດເຂົ້າແຊັດເອງ (ບອກຈຳນວນ, ການຫານ, ມີບິນ/ບໍ່ມີ). ບັນທຶກຈາກແຊັດໄດ້ດ້ວຍປຸ່ມກະເປົາ, ແລະ ກົດ "ສົ່ງລົງແຊັດ" ໃນລາຍລະອຽດເພື່ອສົ່ງຊ້ຳ
- **ຖ້າບໍ່ມີບິນ** — ຕ້ອງເລືອກເຫດຜົນ (ຕະຫຼາດ/ຮ້ານນ້ອຍ, ເງິນສົດ, ໂອນ/QR, ທິບ, ບິນຫາຍ, ອື່ນໆ) ຈຶ່ງບັນທຶກໄດ້. ລາຍການທີ່ບໍ່ມີບິນຂຶ້ນປ້າຍເຫຼືອງ, ກັ່ນຕອງເບິ່ງສະເພາະອັນນັ້ນໄດ້, ແລະ ເພີ່ມບິນຕອນຫຼັງໄດ້
- **ດຶງຂໍ້ມູນ** — ປຸ່ມ ⋯ ມຸມຂວາເທິງແຖບເງິນ: ດາວໂຫຼດ CSV (ເປີດໃນ Excel, ມີຄໍລຳສ່ວນຂອງແຕ່ລະຄົນ), ສຳເນົາສະຫຼຸບເປັນຂໍ້ຄວາມ, ສົ່ງສະຫຼຸບເຂົ້າແຊັດ, ເບິ່ງບິນທັງໝົດ. ກົດແຕ່ລະລາຍການເພື່ອເບິ່ງ/ບັນທຶກຮູບບິນ
- **ສະກິນ "ແຜ່ນເຈ້ຍ" (Paper-cut)** — ເຈ້ຍຕັດຊັ້ນໆ: ພູ, ແມ່ນ້ຳ, ຕົວເມືອງ (ມີທາດຫຼວງ), ປ່າ, ດວງຕາເວັນຄຳ. ຕົວຢ່າງ: ໜ້າເລີ່ມຕົ້ນ, ໜ້າຫຼັກ, ທຣິບ ແລະ ແຖບເງິນ. ໄອຄອນທຸກອັນເປັນເຈ້ຍຕັດ (`icons.js`). ປ່ຽນໄດ້ໃນແຖບທຣິບ → "ໜ້າຕາແອັບ" (ແຜ່ນເຈ້ຍ / ປົກກະຕິ) ແລະ ມີໂໝດກາງຄືນ
- **ເລືອກສະກຸນເງິນ** — ກີບ ₭ / ບາດ ฿ / ໂດລາ $ ຕອນບັນທຶກລາຍຈ່າຍ (ຈື່ສະກຸນທີ່ໃຊ້ຄັ້ງລ່າສຸດ). ແຕ່ລະສະກຸນສະຫຼຸບແຍກກັນ
- **ໂປຣໄຟລ໌** — ເລືອກຮູບ emoji ຫຼື ຕົວອັກສອນ + ສີ
- **ໂໝດມືດ** — ອັດຕະໂນມັດຕາມໂທລະສັບ ຫຼື ເລືອກເອງ
- **ຈຸດນັດພົບ** — ປັກໝຸດ + ເວລາ, ເຫັນວ່າໃຜຮອດແລ້ວ
- **SOS** — ກົດຄ້າງ 1.5 ວິ → ໝູ່ທຸກຄົນເຫັນໜ້າຈໍແດງ + ສຽງເຕືອນ; ມີປຸ່ມ SMS ສຳຮອງ
- **ຄວບຄຸມການແຊຣ໌** — ເປີດ/ປິດ, ຢຸດ 1 ຊົ່ວໂມງ, ເປີດຈໍຄ້າງ
- **ເຂົ້າທຣິບ** — ລະຫັດ 6 ຕົວ, QR, ຫຼື ລິ້ງເຊີນ
- ໃຊ້ໄດ້ offline ບາງສ່ວນ (ແອັບເປີດໄດ້, ແຜນທີ່ທີ່ເຄີຍເບິ່ງ, ຂໍ້ຄວາມສົ່ງເມື່ອມີເນັດ)

ຄ່າໃຊ້ຈ່າຍ: **ຟຣີ** (GitHub Pages + Firebase ແຜນຟຣີ Spark — ບໍ່ຕ້ອງຜູກບັດ).

## ຂັ້ນຕອນທີ 1 — ສ້າງ Firebase (ປະມານ 10 ນາທີ, ຟຣີ)

1. ເຂົ້າ <https://console.firebase.google.com> ດ້ວຍບັນຊີ Google → **Create a project** → ຕັ້ງຊື່ເຊັ່ນ `tripmate` → ປິດ Google Analytics ໄດ້ → Create
2. ເມນູຊ້າຍ **Build → Authentication** → **Get started** → ແຖບ **Sign-in method** → ເລືອກ **Anonymous** → **Enable** → Save
3. ເມນູຊ້າຍ **Build → Realtime Database** → **Create Database**
   - Location: **Singapore (asia-southeast1)** (ໃກ້ລາວທີ່ສຸດ)
   - ເລືອກ **Start in locked mode** → Enable
4. ໃນໜ້າ Realtime Database → ແຖບ **Rules** → ລຶບຂອງເກົ່າອອກ → ວາງເນື້ອໃນທັງໝົດຂອງ `database.rules.json` → **Publish**
5. ກົດ ⚙️ (Project settings) → ລົງລຸ່ມຫາ **Your apps** → ກົດໄອຄອນ **`</>`** (Web) → ຕັ້ງຊື່ `tripmate-web` → Register app
6. ຈະເຫັນ `const firebaseConfig = { ... }` → ສຳເນົາ

## ຂັ້ນຕອນທີ 2 — ວາງ config

ເປີດ `config.js` ແລ້ວປ່ຽນ `null` ເປັນ config ທີ່ສຳເນົາມາ:

```js
export const FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "tripmate-xxxx.firebaseapp.com",
  databaseURL: "https://tripmate-xxxx-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "tripmate-xxxx",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "1:...:web:...",
};
```

⚠️ ຕ້ອງມີ `databaseURL` — ຖ້າບໍ່ມີ ໃຫ້ສຳເນົາ URL ຈາກໜ້າ Realtime Database (ດ້ານເທິງ ຂ້າງໄອຄອນ 🔗).

ຄ່າເຫຼົ່ານີ້ **ເປີດເຜີຍໃນ GitHub ໄດ້** — Firebase ອອກແບບມາໃຫ້ເປັນສາທາລະນະ. ຄວາມປອດໄພມາຈາກ Rules (ຂັ້ນຕອນ 1.4): ອ່ານ/ຂຽນໄດ້ສະເພາະຄົນທີ່ເຂົ້າທຣິບແລ້ວ.

## ຂັ້ນຕອນທີ 3 — ເອົາຂຶ້ນ GitHub Pages

1. ສ້າງ repo ໃໝ່ໃນ GitHub (ເຊັ່ນ `tripmate`) ແລ້ວອັບໂຫຼດທຸກໄຟລ໌ໃນໂຟນເດີນີ້ (ລວມທັງໂຟນເດີ `icons`)
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. ລໍຖ້າ 1–2 ນາທີ → ໄດ້ລິ້ງ `https://<ຊື່-github>.github.io/tripmate/`

> GPS ໃນ browser ເຮັດວຽກສະເພາະເວັບ **https** — GitHub Pages ເປັນ https ໃຫ້ແລ້ວ.

## ຂັ້ນຕອນທີ 4 — ໃຊ້ກັບໝູ່

1. ຄົນທຳອິດ: ເປີດລິ້ງ → ຕັ້ງຊື່ → **ສ້າງທຣິບ** → ໄປແຖບ **ທຣິບ** → **ແຊຣ໌ລິ້ງເຊີນ** (ຫຼື ໃຫ້ໝູ່ສະແກນ QR)
2. ໝູ່: ກົດລິ້ງ → ຕັ້ງຊື່ → ເຂົ້າທຣິບອັດຕະໂນມັດ → ອະນຸຍາດ GPS
3. **ແນະນຳໃຫ້ຕິດຕັ້ງລົງໜ້າຈໍ:**
   - **iPhone**: ເປີດໃນ **Safari** → ປຸ່ມແຊຣ໌ ⬆️ → **Add to Home Screen** → ເປີດຈາກໄອຄອນ → ພິມລະຫັດທຣິບອີກຄັ້ງ
     (iPhone ແຍກຂໍ້ມູນລະຫວ່າງ Safari ກັບແອັບໜ້າຈໍ ຈຶ່ງຕ້ອງເຂົ້າທຣິບໃໝ່ 1 ເທື່ອ)
   - **Android**: Chrome → ⋮ → **ຕິດຕັ້ງແອັບ**

## ຂໍ້ຈຳກັດທີ່ຕ້ອງຮູ້ (ເວັບແອັບ)

- **ແຊຣ໌ຕຳແໜ່ງໄດ້ສະເພາະຕອນເປີດແອັບຢູ່ໜ້າຈໍ.** ປິດຈໍ ຫຼື ສະຫຼັບແອັບ → ໝູ່ຈະເຫັນ "ຕຳແໜ່ງລ່າສຸດ X ນາທີກ່ອນ" (ໝຸດເປັນສີເທົາເມື່ອເກີນ 10 ນາທີ).
  ວິທີແກ້ເວລາແຍກກັນ: ເປີດ **"ເປີດຈໍຄ້າງ"** (ກິນແບັດຫຼາຍຂຶ້ນ). ຖ້າຕ້ອງການແຊຣ໌ຕອນປິດຈໍແທ້ໆ ຕ້ອງເຮັດເປັນແອັບແທ້ (Capacitor) — ໄລຍະ 2 ຂອງແຜນ.
- **ແຈ້ງເຕືອນ**: ເຕືອນໄດ້ຕອນແອັບເປີດຢູ່ (ສຽງ + ຂໍ້ຄວາມ). ຍັງບໍ່ມີ push ຕອນປິດແອັບ ເພາະຕ້ອງມີ server (Cloud Functions ຕ້ອງຜູກບັດ).
- **ແບັດ %** ສະແດງສະເພາະ Android (iPhone ບໍ່ໃຫ້ເວັບອ່ານແບັດ).
- ຮູບເກັບໃນ Realtime Database (ບີບອັດ ≤ 300KB/ຮູບ). ແຜນຟຣີເກັບໄດ້ 1GB ≈ 3,000 ຮູບ — ລຶບທຣິບເກົ່າຖິ້ມເມື່ອທ່ຽວແລ້ວ (ແຖບ ທຣິບ → ລຶບທຣິບນີ້).
- ລະຫັດທຣິບ = ກະແຈເຂົ້າທຣິບ. ຢ່າໂພສລະຫັດໃນທີ່ສາທາລະນະ.
